A highly interactive, professional, and dark-themed business intelligence dashboard built entirely in **Microsoft Excel**. This project transforms raw corporate sales data into actionable, real-time insights using advanced data modeling, dynamic array formulas, and modern UI/UX design principles.

---

## 🔍 Key Features

* **Dynamic Field Parameters (Toggle Buttons):** Switch the entire dashboard view between **Revenue**, **Quantity (QTY)**, and **Orders** with a single click to update all trends and charts instantly.
* **Advanced KPI Tracking:** Monitor critical business metrics (Revenue, QTY, Orders, Avg Order Value, Avg Unit Price) with real-time month-over-month (MoM) performance indicators.
* **Geographical Sales Distribution:** An interactive map visualization showing sales distribution across divisions in Bangladesh.
* **Dynamic Slicers & Filters:** Seamlessly filter data by City, Product Name, and Category using custom-styled interactive slicers.
* **Top & Bottom Performers:** Toggle dynamically between the Top 5 and Bottom 5 performing products based on your active metric selection.

---

## 🛠️ Technical Stack & Methods Used

* **Data Cleaning & ETL:** Utilized **Power Query** to extract, transform, and clean raw data dumps, ensuring proper data types and optimized structures.
* **Advanced Data Modeling:** Developed a robust semantic layer within Excel using highly optimized dynamic array functions, including `LET`, `XLOOKUP`, and nested `INDEX-MATCH` matrices.
* **Custom Number Formatting:** Implemented conditional custom formatting (`[Green]▲ 0%;[Color22]▼ -0%;[White]0%`) to keep the dashboard numbers clean, readable, and visually aligned with the dark mode aesthetic.

## 🚀 How to Download and Run the Project

Follow these simple steps to run the interactive dashboard on your local machine:

### Step 1: Download the Files
1. Scroll to the top of this GitHub repository page.
2. Click on the green **`Code`** button located on the right side.
3. Select **`Download ZIP`** from the dropdown menu.
4. Once the download is complete, extract the ZIP file to your preferred folder on your PC.

### Step 2: Open and Enable Content
1. Open Microsoft Excel (Excel 2021 or Microsoft 365 is highly recommended for full dynamic array compatibility).
2. Open the downloaded `.xlsx` project file.
3. If a yellow warning bar appears at the top saying *"Protected View"* or *"Enable Editing"*, click **`Enable Editing`** to unlock the full interactive features.

### Step 3: Interact with the Dashboard
* Click the **Orders / QTY / Revenue** toggle switches to see the line and bar charts transform dynamically.
* Use the **Filter Panel** on the left to slice data by specific cities or product categories.
